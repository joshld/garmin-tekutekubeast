# v0.4 production atlas prompts

## Six-pose refinements

The selected expressive atlases append a blink and look-back column to the original four poses. They are saved as `*-expressive.png`; originals remain retained.

Use case: precise-object-edit. Image 1 is the EDIT TARGET: the existing TekuTekuBeast shared production pixel-art sprite atlas. Preserve every creature identity, row order, pixel-art rendering, colours and the four existing poses (standing idle, walking, eating, curled sleeping). Expand this into an exact 2 ROWS by SIX COLUMNS evenly spaced grid with equal square cells. Columns 1-4 retain those existing four poses. ADD column 5: same standing idle pose but BLINK with both eyes shut (not eating, no food); ADD column 6: same standing pose but LOOKING BACK over shoulder, alert eyes. All creatures at consistent per-row scale and centered with generous transparent margins. Entire ears, horns, wings and tails visible, absolutely nothing crossing a cell boundary.
