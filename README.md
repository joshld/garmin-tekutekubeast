# StepPal — Garmin Enduro 4 virtual pet

StepPal is a native Connect IQ (Monkey C) watch app which uses **steps recorded by the Enduro 4 itself**. It will support automatic pet evolution through Grove, Ember, Tide and Wisp families, earned rare evolutions, and unlimited post-Legendary mastery. Rest days never kill pets or erase progress.

**Development status:** Prototype source only; not compiled or tested in the Garmin simulator or on an Enduro 4. No installable release yet.

This repository is intended to contain the source code, art assets and evolution design. See Garmin's [Connect IQ SDK](https://developer.garmin.com/connect-iq/sdk/).
