# TekuTekuBeast 0.4.0 - development beta

## What's new

- Developer Mode inside the normal app: accelerate time, preview evolution,
  change test needs/items and reset scenarios without replacing your real beast.
  Discard restores genuine progress and catches up watch steps from testing.
- Your beast grows through time, care and play even with zero activity. Natural
  egg incubation and ongoing Legendary mastery; all four families remain
  reachable without exercise. Activity adds growth and adventure opportunities.
- Meals on rest days, snacks, care gauges, feeding, delayed poop, cleaning,
  petting, resting, moods and personality.
- Play Star Catch, Memory Steps and Trail Treasure. Discover food, toys,
  accessories and collection entries through activity or accessible care/play.
- New concept-inspired pixel artwork across all normal evolution stages,
  with walking, hopping, blinking, eating, sleeping and expressive reactions.
- Cleaner Pet/Care/Details screens and a native pet Glance on compatible models.
- Optional short sounds and gentle vibration with independent settings.
- Expanded individually simulator-tested MIP and AMOLED profiles; see the
  device matrix for exact models and Glance availability.

## Update safely

Update the existing TekuTekuBeast installation; do not uninstall first. The app
ID is unchanged, and legacy progress is migrated without resetting the beast,
genuine watch XP, snacks or friendship. Developer Mode never saves test changes
over real progress. Settings > Developer enables it; Discard exits it.

## Beta limitations

The user has confirmed the Glance now appears on their physical Enduro 4 and
Developer Mode is visible. Save-upgrade integrity, Glance launch/session behaviour,
audible tones, vibration and battery life still need hardware testing. Simulator
testing is not a claim that those hardware checks have occurred. Original Enduro is not
supported by this artwork build because it exhausts memory. Fenix 6X is also
excluded: its smaller background memory budget crashes the step callback.
Rare forms currently use a crown overlay on the family's Legendary sprite.
Running activity type is not inferred; real steps and supported minutes/pushes
are used. See [validation](V0_4_VALIDATION.md) for detailed evidence and limits.
